# Font files

Typography (decision 299): only the FREE Gilroy weights ship, Light (300) and ExtraBold (800). Display headings use Gilroy ExtraBold, light display text uses Gilroy Light, and everything else uses Outfit (400-700, variable). Unbounded (500-600) stays for one short accent phrase.

- `Gilroy-Light.woff2`, `Gilroy-ExtraBold.woff2`: the free release, `LICENSES/Gilroy-Free-Font-EULA.txt`.
- `Outfit-Variable.woff2`: SIL OFL, `LICENSES/OFL-Outfit.txt`.
- `Unbounded-Variable.woff2`: SIL OFL, `LICENSES/OFL-Unbounded.txt`.

The paid Gilroy weights (Regular, Medium, SemiBold, Bold) were removed and must not be re-added.
